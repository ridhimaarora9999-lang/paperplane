# ✈️ Paper Plane — Build, Fold & Fly!

A beginner-friendly website dedicated to the fun of building paper airplanes! This project explores the basics of HTML while sharing the creativity and joy behind paper plane making.

## 🌟 About the Project

Paper Plane is my first web development project, created as I begin my journey into frontend development. It introduces the basics of paper airplane making through a simple and engaging webpage.

## 🚀 Features

* 📄 Simple and beginner-friendly layout
* ✈️ Paper airplane information
* 🖼️ Images and visual content
* 🎥 Embedded tutorial video
* 🔗 Useful links for learning

## 🛠️ Technologies Used

* HTML5

## 📚 What I Learned

* Creating the basic structure of an HTML webpage
* Using headings, paragraphs, images, and links
* Embedding videos using iframes
* Organizing content into sections
* Publishing a website using GitHub Pages
